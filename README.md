# Web Development Career Path

A collection of projects from Codecademy's Web Development career path.

## About The Project

This repository gathers the projects built while following Codecademy's Web Development career path, organized by course module:

- 01 - Learn HTML
- 02 - Styling a Website
- 03 - Getting Started with JavaScript
- 04 - Getting More Advanced with Design
- 05 - JavaScript - Arrays, Loops, and Objects
- 06 - Building Interactive JavaScript Websites
- 07 - Intermediate JavaScript
- 08 - Learn the Command Line
- 10 - Building Front-end Applications with React
- 11 - JavaScript Back-End Development
- 12 - SQL and Databases for Web Development

Each module directory contains its own projects, with their own README files.
